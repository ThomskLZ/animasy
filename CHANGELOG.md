# Mudanças

## 0.1.0
- Primeira versão pública: programa de PC (Electron) pra ver e ajustar animações de personagens 3D.
- Camadas com peso, escopos Quadro/Trecho/Inteira, mover junta (IK, coluna), espelhar, pé no chão, emendar loop,
  pose a pose, biblioteca de poses, acessórios nos encaixes, painel de chaves e curvas, fantasmas.
- Trazer animação de outro modelo com prévia (primeiro passe).
- Salvar `.glb` com conferência quadro a quadro; excluir manda pra lixeira.
- Atualização automática pelo GitHub Releases (instalador do Windows).
